# agent-vcr v0.2.5 实施方案

## 1. 开发目标

v0.2.5 实现 Behavior Visualization：

- 单 run 行为过程可视化。
- 双 run 行为路径对比。
- 3-5 个 run 多泳道对比。
- first divergence 高亮。
- 文件访问对比。
- metrics cards。
- 静态 HTML / JSON 输出。

v0.2.5 不实现：

- HarnessMetadata / HarnessDiff。
- Matrix Compare。
- Regression / baseline。
- 新 agent adapter。
- LLM explain。
- deterministic replay。

## 5. 全局架构约束

1. `internal/visualize` 不得 import `internal/adapters`。
2. `internal/visualize` 只消费：
   - `internal/trace`
   - `internal/behavior`
   - `internal/redact`
   - `internal/config`
3. 不新增 agent-specific visual model。
4. 不修改 trace schema 核心语义。
5. 不修改 behavior public API，除非 additive 且标记 `NEEDS_INTEGRATION`。
6. 不实现 v0.3+ 功能。
7. HTML 必须使用 `html/template`。
8. 所有用户内容必须 escape。
9. redacted 模式不得泄露 prompt、secret、raw output。

## 7. CLI 验收

必须支持：

```bash
agent-vcr visualize latest --json
agent-vcr visualize latest --html
agent-vcr visualize run-a run-b --html --output compare.html
agent-vcr visualize run-a run-b run-c --json
```

## 8. E2E 验收

E2E 至少构造三个 run：

- Run A：搜索 session → 读测试 → 读源码 → 编辑源码 → 跑测试。
- Run B：搜索 cookie → 读 legacy → 编辑 legacy → 不跑测试。
- Run C：搜索 session → 读源码 → 编辑源码 → 跑测试。

验证：

- 单 run HTML 生成。
- 双 run HTML 显示 first divergence。
- 三 run HTML 显示三条 lane。
- JSON 输出可解析。
- 文件访问矩阵存在。
- metrics cards 存在。
