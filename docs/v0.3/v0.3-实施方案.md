# agent-vcr v0.3 实施方案：HarnessMetadata / Pairwise HarnessDiff

## 1. 目标

v0.3 只做 pairwise harness 分析：

```text
run-a HarnessMetadata
run-b HarnessMetadata
        ↓
HarnessDiff
        ↓
可选关联 v0.2 BehaviorDiff
```

不做 batch matrix，不做 regression，不做 LLM explain。

## 2. 开发阶段

```text
Round 0:
  01-harness-domain-model
  锁定公共接口

Round 1:
  02-harness-detection-and-fingerprints
  03-harness-store-and-cache
  04-harness-diff-engine
  可并行，但要遵守 01 的接口

Round 2:
  05-behavior-impact-correlation
  06-cli-integration-and-output
  07-testing-docs-e2e
  可并行

Round 3:
  08-integration-review-release
  最终验收
```

## 3. 模块列表

| 模块 | 文件 | 是否可并行 | 说明 |
|---|---|---:|---|
| 01 | `01-harness-domain-model.md` | 否 | 先锁定 public types |
| 02 | `02-harness-detection-and-fingerprints.md` | 是 | 检测 AGENTS.md、tools、permission 等 |
| 03 | `03-harness-store-and-cache.md` | 是 | 缓存 harness metadata |
| 04 | `04-harness-diff-engine.md` | 是 | pairwise diff |
| 05 | `05-behavior-impact-correlation.md` | 是，依赖 04 | 关联 v0.2 behavior diff |
| 06 | `06-cli-integration-and-output.md` | 是，依赖 02/03/04 | harness CLI |
| 07 | `07-testing-docs-e2e.md` | 是 | E2E 和文档 |
| 08 | `08-integration-review-release.md` | 否 | 最终审查 |

## 4. 公共接口约束

新增包：

```text
internal/harness
```

硬约束：

- `internal/harness` 不得 import `internal/adapters/**`。
- 不允许在 harness 核心类型中出现 Codex/Kimi/Claude 专用字段。
- 不允许修改 v0.2 behavior public interface，除非 additive 且标记 `NEEDS_INTEGRATION`。
- 不改变 trace schema 核心语义。
- harness diff 不做因果断言。

## 6. 并行开发策略

## 6.1 Round 0：单独执行

先完成模块 01：

- `HarnessMetadata`
- `HarnessDiff`
- `HashRef`
- `FileFingerprint`
- `Detector` interface
- `Store` interface 占位
- JSON schema 稳定测试

完成后再开并行。

## 6.2 Round 1：02 / 03 / 04 并行

- 02 做 detection。
- 03 做 cache/store。
- 04 做 diff engine。

三者只依赖 01 public types。

## 6.3 Round 2：05 / 06 / 07 并行

- 05 依赖 04 和 v0.2 behavior 包。
- 06 依赖 02/03/04。
- 07 负责 docs/E2E，不大改 internal。

## 7. 验证命令

每轮都要跑：

```powershell
gofmt -w .
go test ./internal/harness/...
go test ./...
go vet ./...
go build ./cmd/agent-vcr
```

最终还要跑：

```powershell
go run ./cmd/agent-vcr harness --help
go run ./cmd/agent-vcr harness inspect latest --json
go run ./cmd/agent-vcr harness diff <run-a> <run-b> --json
powershell -ExecutionPolicy Bypass -File .\scripts\e2e.ps1
```

如果需要 v0.3 专用脚本：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\e2e-v0.3.ps1
```

## 8. 验收标准

v0.3 验收必须证明：

- 可以为 run 生成 harness metadata。
- 能识别 AGENTS.md hash 差异。
- 能识别 tool set / MCP / permission / config 差异。
- 能输出 pairwise harness diff。
- 能关联 first behavior divergence，但不做因果断言。
- JSON 输出可解析。
- README / docs 不恢复 Matrix/Regression 路线。
- v0.2 behavior CLI 未被破坏。
