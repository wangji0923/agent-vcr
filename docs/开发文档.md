# Agent VCR 开发文档

> 版本：v0.2 开发落地文档
> 日期：2026-06-04
> 技术栈建议：Go 1.23+
> 第一版目标：Codex CLI / Codex 客户端优先，交付 Trace Foundation + Event-level Diff，保留多 Adapter 架构
> 使用方式：本文件是总开发索引；具体开发请按 01 到 08 模块文档逐步执行。

---

## 0. 本版开发文档的核心约束

本项目第一版虽然 Codex first，但核心定位是 Behavior Diff / Harness Diff
底座。代码结构必须支持后续让更多 harness 产出可比较的 normalized trace，
但 v0.2-v0.5 主线是 pairwise behavior / harness diff，而不是 batch matrix
或 benchmark 平台。

硬性约束：

```text
1. Codex 相关逻辑只能存在于 internal/adapters/codex。
2. internal/analysis 不得 import internal/adapters/*。
3. internal/report 不得 import internal/adapters/*。
4. internal/check 不得 import internal/adapters/*。
5. internal/trace 不得 import internal/adapters/*。
6. 所有 adapter 必须输出 normalized trace.Event。
7. 新增 adapter 不允许修改 replay / diff / check 核心逻辑，除非新增通用事件类型。
8. Normalize 失败必须落 RawEvent，不能丢事件，不能阻塞 agent。
9. hook 命令默认不得向 stdout 输出任何内容。
10. hook 出错必须 exit 0。
```

## 5. Adapter 开发指南

### 5.1 新增 Adapter 的最小步骤

1. 在 `internal/adapters/<name>/` 新建目录。
2. 实现 `Adapter` 接口。
3. 声明 `Capabilities`。
4. 实现 `Probe`。
5. 如果支持安装，提供 `Install` / `Uninstall`。
6. 实现 `Normalize(raw RawEvent) ([]trace.Event, error)`。
7. 失败时输出 `trace.EventRaw`。
8. 加入 `registry.Register(...)`。
9. 添加 testdata fixture。
10. 添加 golden test，确认 normalized trace 稳定。

### 5.2 Adapter 不允许做什么

```text
不允许直接写 report。
不允许直接执行 replay / diff / check。
不允许绕过 Trace Store 自己写 trace.ndjson。
不允许把 Codex/Kimi/Claude 特定字段塞进通用字段。
不允许 normalize 失败后 panic。
```

### 5.3 Adapter 允许保存原始字段的位置

```json
{
  "source": {
    "adapter": "codex-hooks",
    "raw_event_type": "PreToolUse"
  },
  "raw_ref": {
    "kind": "blob",
    "path": "blobs/raw_evt_001.json"
  }
}
```

## 6. Codex 执行建议

不要一次性执行：

```text
请实现整个 agent-vcr 项目。
```

应该按模块执行：

```text
请只阅读 docs/01-bootstrap.md，并只完成该模块。
不要实现后续模块。
完成后运行 go test ./...。
输出修改文件、测试结果和未完成项。
```

每个模块完成后必须：

```bash
go test ./...
go run ./cmd/agent-vcr --help
```

对应模块有额外命令时，按模块文档执行。

---

## 7. 开发完成定义

一个模块只有满足以下条件才算完成：

1. 文件结构符合模块文档。
2. public struct / function 与文档命名一致。
3. 有单元测试。
4. 有 fixture 或 golden test。
5. `go test ./...` 通过。
6. 不破坏前面模块功能。
7. 不违反 Adapter 隔离约束。
8. 最后输出完成报告。
