# v0.2 BehaviorSignature

v0.2 turns normalized `trace.Event` records into adapter-independent behavior
steps and compares two runs at the behavior level.

## Scope

Implemented in v0.2:

- `behavior.Step` extraction from normalized trace events
- `BehaviorSignature` generation
- first behavior divergence between two runs
- behavior metrics for context discipline, validation behavior, edit scope, tool
  efficiency, and recovery behavior
- CLI output for behavior timeline, behavior diff, and behavior metrics

Not implemented in v0.2:

- HarnessMetadata
- HarnessDiff
- Matrix Compare
- Regression or baseline tracking
- LLM Explain
- deterministic replay
- new agent adapters

## Behavior Steps

Behavior steps are stable, generic summaries of low-level trace events. Common
step kinds include:

- `search`
- `read_file`
- `inspect_test`
- `edit_file`
- `run_test`
- `run_build`
- `call_tool`
- `call_mcp_tool`
- `recover_from_error`
- `unknown`

Step fingerprints ignore volatile details such as timestamps, event indexes,
blob paths, and user-specific absolute path prefixes.

## CLI

```bash
agent-vcr behavior latest
agent-vcr behavior latest --json
agent-vcr behavior metrics latest
agent-vcr behavior metrics latest --json
agent-vcr behavior diff <run-a> <run-b>
agent-vcr behavior diff <run-a> <run-b> --json
```

`agent-vcr diff` remains the v0.1 event-level diff. `agent-vcr behavior diff`
is the v0.2 BehaviorSignature diff and reports the first behavior divergence.

## Limitations

BehaviorSignature is a rule-based local analysis. It does not re-execute runs,
does not call an external LLM, and does not inspect hidden model reasoning.
Metrics are factual indicators, not a risk score or security firewall.
